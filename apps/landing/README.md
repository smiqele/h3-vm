# h3llo cloud landing

Основная версия лендинга без Next и React. Используется для развития дизайна, идей и тестирования.

## Запуск

Из корня репозитория:

```bash
npm run dev
```

Лендинг откроется на `http://127.0.0.1:4175`.

## Сборка

```bash
npm run build:landing
```

Результат появится в `apps/landing/dist`.

## Структура

- `index.html` — разметка страницы
- `src/styles.css` — все стили и адаптив
- `src/main.js` — калькулятор и анимации
- `public/media` — шрифты, иконки и видео

# Cloud Console Design Lab

## Лендинг h3llo cloud

Текущий лендинг находится в [`apps/brand`](apps/brand). Главная страница собирается в [`apps/brand/src/app/page.tsx`](apps/brand/src/app/page.tsx).

### Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev:brand
```

После запуска лендинг доступен по адресу [http://127.0.0.1:4175](http://127.0.0.1:4175).

### Сборка

```bash
npm run build --workspace @cloud/brand
npm run start --workspace @cloud/brand
```

Проектная документация находится в [`packages/docs/readme.md`](packages/docs/readme.md) и доступна в приложении через раздел Docs.

В прототипе консоли кнопка с иконкой колонок рядом со сменой темы циклически переключает ширину AppShell: 1680 px → 1920 px → вся ширина → 1680 px. Ограниченная оболочка выравнивается по центру; по умолчанию выбрана вся ширина. Кнопка не содержит подписи: текущий и следующий режим указаны в подсказке и доступном имени. Настройка сохраняется в браузере; прежний выбор полной ширины сохраняется при переходе на новые режимы.

Главная страница прототипа — sitemap доступных экранов. Compute содержит две версии списка виртуальных машин: `/compute/vms` без границ и `/compute/vms/bordered` с границами. Переключатель вариантов убран со страницы; логотип консоли возвращает к sitemap. Старые ссылки с `?metrics=default` продолжают работать.

Новая версия сервиса «Виртуальные машины» находится по адресу `/virtual-machines`. В ней есть переключение и создание проектов, разделы инстансов, бэкапов и IP-адресов, блок аккаунта с балансом, профиль, смена темы и поддержка. Данные в новой версии демонстрационные; проекты сохраняются в браузере.

## Основной лендинг без Next

Рабочая версия для развития и тестирования находится в `apps/landing`. Она использует обычные HTML, CSS и JavaScript с Vite, без React и Next.

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:4175`. Для проверки production-сборки используйте `npm run build:landing`.

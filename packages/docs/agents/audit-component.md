# Аудит компонента

Аудит является проверкой соответствия, а не разрешением автоматически менять API или продуктовую логику.

## Контрольный список

1. Сопоставить TypeScript API с Props table.
2. Сопоставить component tokens с Geometry и Tokens.
3. Проверить варианты и состояния из `components.yaml`.
4. Убедиться, что Preview содержит один экземпляр и полезные controls.
5. Проверить синхронизацию Preview и Code.
6. Проверить system, light и dark theme scopes независимо от темы страницы.
7. Проверить mouse, keyboard, focus, disabled и ARIA.
8. Проверить компонент в узкой области и известном продуктовом контексте.
9. Запустить `npm run docs:check` и `npm run check`.

## Результат

Сначала перечисляются ошибки, риски и расхождения со ссылками на конкретные файлы. Если расхождений нет, фиксируются выполненные проверки. Неуверенность и непроверенные состояния указываются явно.

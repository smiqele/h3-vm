# Виртуальные машины

**Service:** `service.compute.vm`  
**Resource:** `resource.compute.vm`  
**Lifecycle:** available

## Назначение

Сервис позволяет управлять вычислительными ресурсами Workspace: находить виртуальные машины, оценивать их состояние, создавать, запускать, останавливать и удалять.

## Пользователи и задачи

Администратор Workspace и разработчик должны быстро определить состояние инфраструктуры, создать подходящую конфигурацию, получить сетевые данные и безопасно выполнить операцию.

## Scope текущего прототипа

Реализован список ВМ по маршруту `/compute/vms`: сводка, поиск, фильтры, выбор строк и таблица ресурсов. Создание, детали и полноценные массовые операции описаны моделью, но ещё не представлены завершёнными маршрутами.

## Ресурс и операции

ВМ имеет вычислительную конфигурацию, образ, регион, сетевые адреса и дисковое пространство. Канонические поля, permissions и переходы находятся в соседнем `resource.yaml`.

```text
creating → running → stopping → stopped → starting → running
     └──→ error                              └──→ deleting
```

Удаление необратимо и требует подтверждения. Доступность операции определяется приложением на основании permission, lifecycle и ограничений; таблица и кнопка не вычисляют эти правила самостоятельно.

## Основные сценарии

- найти ВМ и понять её состояние;
- сравнить ресурсы по конфигурации и использованию;
- создать ВМ в доступном регионе и квоте;
- остановить или запустить ВМ;
- удалить ВМ с подтверждением последствий;
- понять причину неуспешной операции и следующий шаг.

## Метрики и гипотезы

| Метрика | Назначение | Статус |
|---|---|---|
| Time to identify failed VM | Проверка структуры списка и группировки данных | Гипотеза `HYP-001` |
| Create-flow completion | Проверка сложности создания | Не измеряется |
| Time to running | Проверка ожидания долгой операции | Определена в CJM |
| Quota error rate | Проверка раннего объяснения ограничений | Определена в CJM |

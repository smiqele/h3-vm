# Управляемые базы данных

**Service:** `service.database.cluster`  
**Resource:** `resource.database.cluster`  
**Lifecycle:** prototype

## Назначение

Сервис должен позволять создать и управлять кластером базы данных выбранного движка и версии без ручного управления базовой инфраструктурой.

## Пользователи и задачи

Разработчик или администратор Workspace выбирает движок, версию и регион, создаёт кластер, отслеживает его готовность и получает данные подключения.

## Scope

В продуктовой модели существуют список и создание кластера. Полноценный маршрут прототипа, операции, переходы, permissions, quotas и модель подключения ещё не реализованы. Поэтому документ нельзя считать точным контрактом сервиса.

## Предполагаемые сценарии

- найти кластер и оценить состояние;
- создать кластер PostgreSQL или MySQL;
- дождаться готовности;
- получить параметры подключения;
- понять ограничения версии, региона и квоты;
- безопасно удалить кластер.

## Метрики-кандидаты

| Метрика | Назначение | Статус |
|---|---|---|
| Create-flow completion | Проверка выбора движка и конфигурации | Кандидат |
| Time to connection-ready | Проверка пути от создания до использования | Кандидат |
| Configuration correction rate | Поиск непонятных или несовместимых параметров | Кандидат |

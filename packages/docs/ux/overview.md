# UX

UX-слой описывает поведение облачной консоли: пользовательские задачи, навигацию, состояния ресурсов, операции, ограничения и обратную связь.

Документы объясняют принципы и причины решений. Машиночитаемые ресурсы, экраны, fixtures и CJM хранятся внутри соответствующих `packages/docs/domains`, общие паттерны — в `packages/docs/ux`, затем компилируются в console runtime и исполняются в Design Lab.

```text
UX-документ
→ исполняемый паттерн
→ состояние экрана
→ UI-компоненты
→ продуктовый сценарий
```

## Область ответственности

- общие правила взаимодействия для всех облачных сервисов;
- жизненные циклы ресурсов и доступные операции;
- ожидание, успех, ошибки и частично выполненные операции;
- роли, права, квоты и ограничения;
- связь экранов с пользовательскими задачами и CJM.

UX-слой не задаёт визуальные значения компонентов. Цвет, типографика, размеры и реализация компонентов принадлежат UI-слою.

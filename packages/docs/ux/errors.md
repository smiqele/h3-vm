# Errors

Ошибка должна объяснять произошедшее, состояние системы и возможное продолжение работы.

## Структура сообщения

- что не удалось сделать;
- какой ресурс или данные затронуты;
- изменилось ли состояние системы;
- может ли пользователь повторить действие;
- какой следующий шаг доступен.

## Ошибки операций

Не следует показывать успешное состояние до подтверждения результата. Если операция завершилась ошибкой, интерфейс сохраняет или восстанавливает подтверждённое состояние ресурса.

Повтор действия предлагается только для retryable-ошибок. Для ошибок прав, квот или некорректной конфигурации интерфейс объясняет способ устранения причины.

## Ошибки загрузки

Если часть страницы остаётся полезной, ошибка не должна заменять весь экран. Сохраняются доступные данные, навигация и действия, которые не зависят от сбоя.

## Валидация

Ошибки полей показываются рядом с соответствующим значением. Сообщение описывает способ исправления, а фокус после отправки переводится к первой ошибке.

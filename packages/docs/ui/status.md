# Status

Универсальный маркер с текстом. Один вариант `inline`, один размер: текст 14/16 px,
область индикатора 16 px, маркер 8 px по центру, промежуток до текста 4 px.
Параметров `size` и `variant` пока нет.

```tsx
<Status tone="positive">В норме</Status>
<Status tone="progress" animated>В процессе</Status>
<Status tone="unknown">Нет данных</Status>
<Status tone="warning" icon="triangle-alert">Высокая нагрузка</Status>
```

`tone` по умолчанию `neutral`, `animated` — `false`. Опциональная `icon` заменяет
круглый маркер и отображается размером 12 px в той же области 16 px, сохраняя gap
и цвет текущего tone. `emphasis="secondary"` ослабляет только подпись, не меняя
цвет маркера или иконки. `children` содержит видимую
подпись; маркер скрыт от скринридера. Поддерживаются стандартные атрибуты span.
Длинный текст переносится в доступной ширине без потери содержания.
Компонент не объявляет каждую ячейку таблицы live region; для важных обновлений
приложение может передать `role="status"`. Анимация отключается при
`prefers-reduced-motion: reduce`.
В режиме `animated` пульсирует круглый фон размером 16 px: от прозрачного
до 10% цвета текущего тона. Центральный маркер остаётся неподвижным и непрозрачным
(для `unknown` — полым). При отключённой анимации фон остаётся на уровне 10%.

| Тон | Смысл |
| --- | --- |
| positive | Штатно активно, доступно |
| neutral | Штатно неактивно |
| progress | Переходное состояние, выполняется операция |
| warning | Ограничения, требуется внимание |
| danger | Сбой или недоступность |
| unknown | Нет достоверных данных; полый маркер |

Размеры используют `component/status/*`, цвета маркеров — `status/*`,
текст — `text/primary`. Тема меняется через общие токены.

Названия ВМ, дисков и IP, машинные статусы и их маппинг находятся в
`packages/docs/ui/resource-statuses.yaml`. В UI нет `running` и других ресурсных
значений. Приложение получает представление и передаёт визуальные свойства:

```tsx
const { label, tone, animated } = getVmStatusPresentation(vm.status);
return <Status tone={tone} animated={animated}>{label}</Status>;
```

Старый `ResourceStatus` удалён; текущие экраны используют эту композицию.
